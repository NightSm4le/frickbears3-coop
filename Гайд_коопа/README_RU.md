# Кооп: установка, персонажи и обновление

Актуальная цель исходников — **Five Nights at Frickbear's 3 + Four Layers Down v2.1.5**. В GitHub хранятся исходники мода и скрипты, но не игровые файлы: для сборки нужны чистый `data.win` этой версии и UndertaleModTool CLI.

## Что делает L и почему эффект не гарантирован

В офисе клавиша **L** отправляет аудиоприманку в офис партнёра; у неё перезарядка 15 секунд. Она пытается отвести подходящего аниматроника, уже близкого к нападению, с шансом 80%. Эффекта не будет, если такой угрозы рядом нет или случайная попытка не удалась. Теперь инициатор и партнёр получают сообщение о результате, а кнопка подписана `L (partner)`.

**Ultra Clock** сбрасывает общий таймер ночи на обоих клиентах: если предмет использовал не хост, игра отправляет хосту запрос, а он применяет эффект и рассылает новое время. Обычное ускорение таймера клиента больше не должно визуально откатываться к прежнему времени хоста.

## Сборка и установка

В PowerShell из папки репозитория соберите обычную версию:

```powershell
.\scripts\build.ps1 -BaseData "C:\Games\Frickbears3\data.win" -UndertaleModCli "C:\Tools\UndertaleModCli.exe"
```

Результат: `build\data_coop_v215.win`. Скрипт проверяет сборку и не заменяет исходный файл игры.

Чтобы установить её, закройте игру и выполните:

```powershell
.\scripts\install_data_win.ps1 -GameDir "C:\Games\Frickbears3" -BuiltDataWin ".\build\data_coop_v215.win"
```

Установщик попросит подтверждение, сохранит оригинал как `data.win.coop-backup` и только затем заменит `data.win`. Если такая резервная копия уже есть, установка остановится, чтобы её случайно не перезаписать. Для отката закройте игру, удалите установленный `data.win` и верните резервную копию на имя `data.win`.

**Самый простой вариант с BAT:** положите `install_build.bat` и собранный файл рядом друг с другом в подпапку внутри папки игры. Файл сборки должен называться `data.win`. Двойной щелчок по BAT заменит игровой файл, предварительно сохранив оригинал как `data.win.coop-backup`. В готовой папке рядом с игрой уже есть два подготовленных варианта: `Coop_Install` — обычный кооп, `Admin_Install` — админская сборка. Откройте только нужную папку и запустите соответствующий BAT.

## Отдельная админ-сборка

Соберите её отдельно:

```powershell
.\scripts\build.ps1 -BaseData "C:\Games\Frickbears3\data.win" -UndertaleModCli "C:\Tools\UndertaleModCli.exe" -AdminCheats
```

Она создаёт `build\data_coop_v215_admin.win`; обычная сборка не содержит этих читов. Админ-версия:

- автоматически открывает персонажей, аниматроников, трофеи и мини-игры;
- **F6** — включить/выключить бесконечную энергию;
- **F7** — выдать ещё 100 000 денег.

Прогресс админ-версии хранится отдельно в файлах с суффиксом `_coop_admin`; обычное сохранение не используется для её прогресса. Команды не являются сетевыми командами, хотя партнёр может видеть обычные синхронизируемые игровые показатели. Это разделение сборок, **не защита по аккаунту**: если передать админский `data.win` другому человеку, игра не сможет надёжно запретить ему пользоваться читами. Не отправляйте ему этот файл.

Чтобы использовать админ-сборку в коопе, установите её через тот же скрипт, указав `-BuiltDataWin ".\build\data_coop_v215_admin.win"`. Второму игроку нужна обычная сборка.

## Свои персонажи и спрайты

Кооп использует PNG-спрайты, а не 3D-модель. Формат и примеры:

- `coop_art/README.md` — PNG для лабиринта, портреты и иконки;
- `scripts/import_addon_skin.py` — преобразование графики персонажа из `addons/<имя>` в статичный кооп-спрайт.

Для карточки перед ночью каждый участник должен иметь локально тот же аддон персонажа: игра ищет `addons/<имя>/selection.png`. Чтобы увидеть одинаковые изображения на обоих компьютерах, обоим игрокам нужны одинаковые аддоны и PNG. Преобразование `selection.png` создаёт статичный образ; кадры для анимации можно нарисовать отдельно по описанному шестикадровому формату.

## Перенос коопа на новую версию игры

Каждое обновление игры требует новой сборки и проверки; нельзя безопасно переносить прежний `data.win` поверх новой игры. Нужны чистый `data.win` новой версии и UndertaleModTool CLI, совместимый с этим файлом. Затем:

1. Сохраните исходники и получите чистый `data.win` новой версии.
2. Запустите сборку обычной версии и отдельно `-AdminCheats`, если нужна админская.
3. Если сборка или `tests/verify.csx` сообщают об отсутствующем hook, обновите соответствующие точки в `scripts/apply.csx` под новую декомпиляцию; не обходите ошибку проверки.
4. Проверьте в игре запуск, открытие/закрытие Co-op Settings, начало ночи, соединение двух игроков, синхронизацию и аддон-спрайты.
5. Только после проверки установите соответствующую сборку. Не раздавайте `data.win` игры или CLI вместе с исходниками.

Статическая проверка подтверждает наличие интеграционных точек, но не заменяет запуск игры и двух клиентов. Известная причина сбоя в описании Co-op Settings исправлена: код теперь получает настройки через локальную ссылку `global.CoopCfg`; всё равно проверьте экран в самой игре после сборки.
